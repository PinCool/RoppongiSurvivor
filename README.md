# 六本木サバイバー（LINE ミニアプリ版・試作）

上京してきた主人公が、六本木の夜の街で No.1 を目指す夜職育成シミュレーション。

- 自宅（ホーム）で自分磨き → **出勤** → 街で集客（ヴァンサバ風・3 分）→ 店で接客（ノリの 3 択 → ドリンクのおねだり）→ 帰宅して寝る
- 4 週で 1 か月。月末に家賃。半年滞納すると実家に呼び戻されてゲームオーバー

```bash
npm install
npm run dev      # ブラウザで開く（WASD / 矢印 / 画面ドラッグで移動）
npm run check    # 型チェック + テスト
npm run build    # dist/ に静的ファイル
```

開発の決まりは [CLAUDE.md](CLAUDE.md)、企画と実装の対応は [Docs/Design.md](Docs/Design.md)。
