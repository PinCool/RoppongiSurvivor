# 設計メモ — 企画書と実装の対応

企画書: Notion「六本木サバイバー」（LINE ミニアプリ向けに改編したバージョン）。2026-09-25 に v0.1（コアループの試作）を作った。

## 技術の選択（2026-09-25）

**TypeScript + Phaser 4 + Vite。** Unity WebGL は初回ダウンロードが 10〜30MB 超になりがちで、LINE 内ブラウザ（WebView）の
起動の速さとメモリに不安があったので見送った。v0.1 のビルドは JS が gzip 後 約 380KB、絵が約 1.6MB。
Steam 版の設計の決まり（ロジックはエンジン非依存の Core・数値は JSON・文言はキー・テストで規約を見張る）はそのまま持ち込んだ。

### v0.1 で決めた、企画書に無い仕様

- **失敗が 3 回でお客が帰る**（`service.json` の `patience`）。MP を払ってのハズレ乱発に歯止めを掛けるため
- **遅刻（3 分を過ぎた）は売上 7 割**、**HP 切れは接客なし**（同伴も失う）
- 取り分は売上の 50%（`back_rate`）。経験値は集客の粒 ×2 ＋ 売上 1,000 円ごとに 3
- 集客中の自機の成長は「テンション Lv」（粒を拾うと自動で上がり、攻撃力・連射・弾数が伸びる）。レベルアップの選択画面は入れていない

## 難易度の現在地（`tests/balance.test.ts` のボット、2026-09-25）

素直なボット（雑魚から離れ、お客に寄り、お店へ向かう）で 20 回ずつ:
ステージ 1 → 全員到着・残り HP 平均 95・同伴 3 人 / ステージ 10 → ほぼ全員到着・残り HP 平均 60 / 立ち止まると 7 割以上ダウン。
ボットは完璧に逃げるので、人にとってはもう一段むずかしい。実機で触って詰める。

## 音（2026-09-25）

効果音は TokyoSurvivor と同じ Case Portman Audio の 2 パック（Forge & Fantasy / Cute & Cozy UI）。ライセンスは
「ゲームに組み込んで配布は OK・**元の音声ファイルを単体でダウンロードできる形で置くのは NG**」。このリポジトリは public なので、
**音声ファイルは commit しない**: `tools/import_tokyo_sfx.py` が TokyoSurvivor から m4a に変換して `public/assets/audio/`（gitignore）へ置く。
無ければ黙って鳴らさない（`game/audio/sfx.ts`）ので、**いまの公開版（GitHub Pages）は無音**。`tests/voicePolicy.test.ts` が
「git に音声ファイルが無いこと」を見張る。公開版でも鳴らすなら、音を別の private リポジトリに置いて Actions のビルドでだけ取り込む案がある（未決定）。

鳴らし方は TokyoSurvivor の `SfxVoicePolicy` と同じ（同じ音は最短間隔より詰めない・同時発音の上限・波形は直前と別・ピッチは幅で散らす）。
id も TokyoSurvivor の `sfx.json` のまま（命中 = `hit_penlight`、同伴 = `recruit_join`、横取り = `recruit_fail` など）。

## 絵の出どころ（2026-09-25）

`tools/import_tokyo_art.py` が TokyoSurvivor の `Art/Sprites/Characters` から縮小して焼く。**フード（Hood）とリーゼント（Regent）は
TokyoSurvivor でもう使われていない古い絵なので取り込まない**（ユーザー指示「昔のアセットが紛れ込んでいるから完全削除」。表の `RETIRED`・
`tests/assets.test.ts` が見張る）。売れっ子デザイナーはキャッチの絵にした。**色違いは作らない**（同日、酔っぱらいをサラリーマンの赤い色違いで出したら
「色味がダサすぎる AI っぽいのでやめてほしい」—— 酔っぱらいごと外し、`tint` の仕組みも消した。1 つの絵は 1 つの役だけ。`tests/assets.test.ts`）。
なお git の履歴（v0.1 のコミット）には 2 枚の PNG が残っている。

## 見た目の作り直し（2026-09-25）

- **UI**: ユーザー指示「UI 全体の色味」→「LINE ミニアプリで使われているような色味で」→ 同日「LINE ミニアプリのような色味ではなく
  可愛いソシャゲのような色」で着地。パステル × 白い丸角パネル × ぷっくりボタン × 丸ゴシック（`game/theme.ts`）。
- **マップ**: 「マップが低品質なので変えて」→ アイソメの街（推奨を選択）→「六本木の地形データは使わなくていい。遊びやすい街を」。
  - 架空の格子の街（`street.json` の `city`）: 道の間隔 780・道の半幅 160（広め）・区画に建物 2×2・空き地 35%・広場 20%・開始地点の周り 240 は空ける
  - 建物は壁。敵は流れ場（50 マス角の幅優先）で回り込む。**まっすぐ追う頃より敵が強くなった**（壁に張り付かない）ので、
    同時に湧きを画面の外へ遠ざけ（`view.spawn_screen_half_*` 600 × 880）、ステージごとの強化を弱めた（HP +12% → +6%・湧き +4% → +2%）。
    ボットの残り HP はステージ 1 / 5 / 10 で 90 / 73 / 56（街の前は 95 / 75 / 60）と、ほぼ元の曲線に戻した
  - 建物の絵は TokyoSurvivor の 24 棟（WebP で 1.2MB）。発光マスク（_glow）とぼかしは使わない
- **着せ替えの作り方の相談**（同日）: 立ち絵はパーツを重ねる 1 枚絵、街のちびキャラは骨格アニメ（正面待機＋横走りの 2 本・背面なし）を推奨。
